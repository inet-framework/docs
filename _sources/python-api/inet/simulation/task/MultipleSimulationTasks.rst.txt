   Represents multiple simulation tasks that can be run together.

   Initializes a new multiple simulation tasks object.

   :param build: Determines if the simulation project is built before running any simulation.
   :type build: bool
   :param kwargs: Additional arguments are inherited from :py:class:`MultipleTasks <inet.common.task.MultipleTasks>` constructor.
   :type kwargs: dict
